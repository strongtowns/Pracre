## Download

| | Installer | |
|---|---|---|
| **Windows** | [Pracre-Windows-x64-Setup.exe](https://github.com/strongtowns/Pracre/releases/download/v1.1.1/Pracre-Windows-x64-Setup.exe) | Run it; it asks for admin rights to install into Program Files\STCD\Pracre and adds the .pracre file type. If SmartScreen warns about a new app, choose More info, then Run anyway. Windows 10 and 11 |
| **macOS** | [Pracre-macOS-Universal.dmg](https://github.com/strongtowns/Pracre/releases/download/v1.1.1/Pracre-macOS-Universal.dmg) | Open it and drag Pracre to Applications; it is not signed, so on macOS 15 and later click Open Anyway under System Settings > Privacy & Security after the first try, and on earlier versions right-click it and choose Open. macOS 12 or later, Intel and Apple silicon |
| **Ubuntu and Debian** | [Pracre-Linux-x64.deb](https://github.com/strongtowns/Pracre/releases/download/v1.1.1/Pracre-Linux-x64.deb) | `sudo apt install ./Pracre-Linux-x64.deb`, which brings in WebKitGTK. Ubuntu 22.04 or later, Debian 12 |
| **Other Linux** | [Pracre-Linux-x64.tar.gz](https://github.com/strongtowns/Pracre/releases/download/v1.1.1/Pracre-Linux-x64.tar.gz) | Unpack it and run `./install.sh`, which installs for your user without root. Needs GTK 3 and WebKitGTK 4.1 |

`Pracre-Windows-x64-Portable.zip` runs on Windows without installing, and `Pracre-macOS-Universal.zip` holds the macOS app on its own. `SHA256SUMS.txt` lists every file's checksum.

Pracre 1.1.1 keeps exported images and web maps to the map title, and names each sample for the measure it opens with.

Both turned up while making the screenshots for pracre.org on 1.1.0.

**Exports carry the map title alone.** Export Image draws the title bar without the "Half of all tax revenue comes from 3.8% of the land" line, as the summary card has since 1.1.0, and the Export web map dialog starts with an empty subtitle that you can still fill in. The image keeps its map data credit and the web map its "Made with Pracre" link in the corner.

**Samples are named for what they show.** The Township of Langley sample opens on tax revenue, since it ships with its 2024 tax rates, and is now titled "Township of Langley, tax revenue per acre" instead of "value per acre". Port Huron has no rates and stays "Port Huron, value per acre". The title box, the summary card and both exports use that title.
